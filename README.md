# Bearded Dragon Guide

A friendly, practical care guide for a family preparing to keep a bearded dragon in Auckland, New Zealand.

## Live site

Visit the guide at [mikebranstein.github.io/bearded-dragon-guide](https://mikebranstein.github.io/bearded-dragon-guide/).

GitHub Pages publishes the files from the repository root on the `main` branch. Changes appear on the site after they are pushed to `main`; the first publish can take a few minutes.

## View the site

To preview it locally, open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; no build step, dependencies, or user data storage are required.

Use **Print care routine** to print the daily, weekly, and monthly care instructions.

Care information is general guidance, not veterinary advice. Confirm current legal requirements and animal-care details with a reputable reptile store and an exotic-pet vet.
